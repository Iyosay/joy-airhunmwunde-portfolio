# Joy Airhunmwunde — Editorial Personal Brand Site

## Brand direction
A photo-led, editorial personal brand: credible, human, ambitious and technically sophisticated.

## Homepage photography slots
1. Hero portrait — confident editorial image with negative space.
2. About portrait — warmer, candid image.
3. Graduation editorial — gown/campus milestone image.
4. Lifestyle/work image — workspace, walking or candid detail.

Replace each `.photo-slot` placeholder with an image using CSS `background-image:url(...)`, or convert the slot to an `<img>`.

## Deploy on Cloudflare Pages
Upload the project folder (or connect a GitHub repository) to Cloudflare Pages, then attach your .com domain under Custom Domains.

JOY AIRHUNMWUNDE — EDITORIAL PERSONAL BRAND SITE

1. Open index.html to preview locally.
2. Replace each .photo-slot with your own image by adding an <img> element inside the slot, or use CSS background-image.
3. Best photo assets to prepare:
   - hero.jpg — confident editorial portrait, horizontal
   - about.jpg — warm candid portrait
   - graduation.jpg — gown/campus image
   - lifestyle.jpg — working/walking/detail portrait
4. Recommended export size: at least 2000px on the long edge, WebP or high-quality JPEG.
5. Upload all files to Cloudflare Pages. Keep index.html in the project root.
6. Add your .com custom domain from Workers & Pages > project > Custom domains.

Brand direction: editorial, personal, premium, technically credible. The site intentionally treats the CV as supporting evidence rather than the full brand.

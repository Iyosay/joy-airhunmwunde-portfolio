01 / CLOUD ANALYTICS

Cocosurf Gear

Five nested JSON feeds. One trusted analytical layer.

ROLECloud Data Engineer
STACKAWS · Snowflake · dbt · Airflow · Docker · ECS
FOCUSTransformation · Orchestration · Deployment

The engineering question

How do you turn continuously arriving semi-structured data into models that remain testable, deployable and useful to analytics teams?

What I built

An analytical layer transforming five daily nested JSON feeds from Amazon S3 into validated Snowflake models for customers, products, inventory, orders and order items.

The platform modelled historical pricing, net revenue, available-to-promise inventory, customer lifetime value, discount erosion, inactive SKUs and return-rate analysis. dbt was containerised, images were deployed through ECR and transformations ran on ECS Fargate with orchestration.

02 / HISTORICAL MIGRATION

LuminaBrick Properties

Move the history. Protect the production system.

ROLEData Engineer
STACKPostgreSQL · Python · SQL · Amazon S3
FOCUSZero-downtime extraction · Validation

The engineering question

How do you deliver seven years of business-critical data to a data science team without turning the live acquisition platform into an analytical workload?

Architecture decision

Designed a schema-preserving extraction approach across five critical PostgreSQL tables covering real-estate transactions, renovation costs, demographics and zoning history. Delivery was planned into Amazon S3 so model development could happen away from the production database.

03 / LAKEHOUSE RELIABILITY

AI-Driven Schema Drift Detection

Detect the change. Predict the blast radius. Choose the response.

RESEARCHApache Iceberg lakehouse reliability
STACKPython · Docker · PostgreSQL · Random Forest · Graph modelling
EVALUATION227 metadata snapshots

The engineering question

A schema change is rarely local. How can a platform predict downstream impact and automate a response before the issue becomes a failed pipeline or bad analytical output?

System design

Built a graph-based propagation model across a three-tier lakehouse hierarchy and a remediation engine mapping severity to log, review, quarantine or pipeline-halt actions.
